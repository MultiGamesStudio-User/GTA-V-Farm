# Contributing to MacroEngine

First off, thanks for your interest in contributing! 🎉

## How to Contribute

### 1. Report Bugs
- Check [Issues](https://github.com/MultiGamesStudio-User/GTA-V-Farm/issues) first (don't create duplicates)
- Provide:
  - Clear description
  - Steps to reproduce
  - Expected vs actual behavior
  - Screenshots/logs if relevant

### 2. Suggest Features
- Open a [Discussion](https://github.com/MultiGamesStudio-User/GTA-V-Farm/discussions)
- Explain the use case
- Discuss before implementing

### 3. Submit Code Changes

#### Setup
```bash
git clone https://github.com/MultiGamesStudio-User/GTA-V-Farm.git
cd "GTA V FARM"
npm install
npm run dev
```

#### Guidelines
- **Branch naming:** `feature/description` or `fix/description`
- **Commits:** Clear, descriptive messages (e.g., "fix: OCR detection timeout")
- **Code style:** Follow existing patterns (no reformatting unrelated code)
- **Testing:** Test manually on Windows 10/11
- **PR description:** Link related issues, explain changes

#### Before Submitting
```bash
npm run build        # Ensure it builds
npm run dev          # Test locally
```
