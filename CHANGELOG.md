# Changelog

All notable changes to MacroEngine are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [2.2.0] – 2024-04-19

### Added
- ✨ Professional installer (NSIS) with auto-updates
- ✨ Fishing automation module
- 📊 RAM usage monitor in overlay
- 🔄 Humanize option for macro timing
- 🎛️ Improved conditions editor UI

### Fixed
- 🐛 Fixed conditions editor crash
- 🐛 OCR detection false positives in menu
- 🐛 Loop action not resetting state

### Changed
- 📦 Migrated to electron-builder for builds
- 🚀 Auto-update system via GitHub releases
- 📚 Complete documentation overhaul

---

## [2.1.0] – 2024-02-10

### Added
- 🖼️ Image template management UI
- 🎨 Dark theme improvements
- ⌨️ Keyboard shortcut customization

### Fixed
- 🐛 Screen capture lag on high-res displays
- 🐛 Memory leak in image analyzer

## [2.0.0] – 2024-01-15
